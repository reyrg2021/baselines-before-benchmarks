# Data

Only the cycle-level split is distributed here. The audio is obtained from its providers.

## Included

`splits/strategy1_official/{train,val,test}_cycles.csv`: one row per respiratory cycle,
with the cycle identifier, patient, class, recording device, chest location, acquisition
mode, and source recording. These are the partitions of the article
(3350 / 635 / 2733 cycles; 64 / 15 / 49 patients) and the same files as Supplemental
Data S2. Validation and training share no patient. The official ICBHI 2017 list assigns
patients 156 and 218 to both training and test; it is used without modification.

## To download

### ICBHI 2017 Respiratory Sound Database

Source: <https://bhichallenge.med.auth.gr/ICBHI_2017_Challenge> (freely available for
research). Extract the database so that the 920 WAV files, their 920 annotation TXT files,
and the official files sit directly in `data/raw/`:

```
data/raw/
├── 101_1b1_Al_sc_Meditron.wav
├── 101_1b1_Al_sc_Meditron.txt
├── ...
├── ICBHI_challenge_train_test.txt     # official train/test list (scripts 07, 28, 30)
└── ICBHI_Challenge_diagnosis.txt      # diagnosis per patient (patient-level AUC in script 29)
```

The database providers ask users to cite Rocha et al., *Physiological Measurement* 40,
035001 (2019).

### SPRSound (Table 15 only)

Source: <https://github.com/SJTU-YONGFU-RESEARCH-GRP/SPRSound>. Scripts 25 to 27 expect
the BioCAS 2022 release in `data/SPRSound/BioCAS2022/`, with the folders
`train2022_wav/`, `train2022_json/`, `test2022_wav/`, and `test2022_json/inter_test_json/`.

### PANNs CNN6 weights (script 22 only)

`Cnn6_mAP=0.343.pth` from Kong et al., <https://doi.org/10.5281/zenodo.3987831>
(CC BY 4.0). Place it in `models/checkpoints/` and pass it with `--weights_path`.
